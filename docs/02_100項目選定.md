# 診療報酬100項目 暗記アプリ：100項目の選定（STEP 4）

作成日：2026-11-10　対象：令和8年度（2026年度）診療報酬（2026年6月1日適用）

## 先に結論

- 令和8年度の医科診療報酬点数表（告示）から区分番号と名称を抜き出し、病院の経営改善の会議で出やすい順に100項目を選びました。
- 内訳は、入院料25・入院加算30・リハ15・在宅医学管理15・外来救急その他15です（ご提示の配分どおり）。
- 優先度は A＝会議で頻出・収益への影響が大きい（43項目）、B＝標準（45項目）、C＝余力があれば（12項目）です。
- 令和8年度に新しく見える名称が12項目あります（表の「R8」欄に「新」）。急性期病院A・B一般入院料、急性期総合体制加算、物価対応料などです。令和6年度の点数表にない名称なので、STEP 5 で改定の概要資料と照らして、何が再編されたのかを確かめます。
- この段階で確かめたのは「令和8年度の点数表に、この名称と区分番号で載っていること」だけです。概要・要件・点数は、カードを作るときに一次情報で確認します。

## 2. 選び方

1. **1項目＝会議で1つの言葉として出てくる単位**にしました。点数表の細かい区分（入院料1〜6など）は、会議で区別して話される場合だけ別の項目にしています。例えば、急性期一般入院料1（旧7対1）は単独の項目にし、入院料2〜6はまとめました。
2. **病棟機能の選択に関わる入院料**を最優先にしました（急性期・地域包括医療・地域包括ケア・回復期リハ・療養）。
3. **届出の有無で収益が動く加算**（看護配置・看護補助・医師事務・データ提出・入退院支援など）を優先しました。
4. 結核病棟、有床診療所、歯科・調剤、検査・画像・手術の個別項目は、今回の対象から外しました。

## 3. 学習の順番

- アプリは表の上から順に、**1日4項目**ずつ新しいカードを出します。100項目は25学習日（週5日で5週間）で一巡し、6週目は総復習にあてられます。
- ご提示の週ごとの配分（15・10・20・25・30項目）は分野の順番として使います。1日の数を一定にするので、週の区切りは少しずれます。配分どおりにすると第5週が1日6項目になり、目安の3〜5項目を超えるためです。

| 学習日 | 範囲 | 内容 |
|---|---|---|
| 1〜4日目 | NY-001〜015 | 主要な入院基本料と、病棟機能を選ぶときの入院料 |
| 4〜7日目 | NY-016〜025 | 特定入院料（ICU系・小児・緩和・精神など） |
| 7〜12日目 | KS-001〜020 | 頻出の入院加算 |
| 12〜18日目 | KS-021〜030、RH-001〜015 | その他の入院加算とリハビリ |
| 18〜25日目 | ZT-001〜015、GK-001〜015 | 在宅・医学管理、外来・救急・その他 |

## 5. 今回は外した候補

| 候補 | 外した理由 |
|---|---|
| DPC／PDPS、機能評価係数Ⅱ | 会議では頻出ですが、医科点数表ではなく別の告示で決まる仕組みです。100項目とは別に「制度・用語」の枠で扱う方がよいと考えます |
| 重症度、医療・看護必要度、平均在院日数、在宅復帰率 | 点数ではなく、入院料の施設基準で使う指標です。各入院料のカードの要件欄で扱います |
| 入院時食事療養費、選定療養（特別の療養環境の提供など） | 医科点数表の外で決まる仕組みです。上と同じく「制度・用語」の枠の候補です |
| 外来・在宅ベースアップ評価料、看護職員処遇改善評価料 | 入院ベースアップ評価料（GK-003）のカードの類似項目として扱います |
| 夜間看護体制加算、看護配置加算、療養環境加算 | 優先度が低いため外しました。入れ替えの候補です |
| 精神科リエゾンチーム加算、重症患者初期支援充実加算、褥瘡ハイリスク患者ケア加算、せん妄ハイリスク患者ケア加算 | 同上 |
| 認知症治療病棟入院料、特定一般病棟入院料、特定機能病院リハビリテーション病棟入院料 | 同上 |

## 6. STEP 5 に向けた注意

- 1つの区分番号に複数の項目を対応させている場合（例：A100 → NY-001〜005）は、カードの点数欄にその項目の区分だけを載せます。
- 「新」の付いた項目は、改定の概要資料で、旧制度のどの項目が再編されたのかを確かめてから `revNote` に書きます。
- ZT-004・ZT-009 は点数ではなく施設基準の名称です。点数の欄は使わず、「届け出ると算定できるようになる主な点数」を要件の欄に書きます。
