# 診療報酬100 暗記アプリ

主要な診療報酬100項目（令和8年度）を、「名称を聞いたら何の報酬か言える」状態にするための暗記アプリです。
作りは医療情報基礎知識検定アプリ（`apps/iryo-joho-kentei`）と同じで、1枚のHTML・インストール不要・オフラインで動きます。

## 使い方

1. ホームの「学習を始める」を押す（その日の復習カードと新しい項目のカードが混ざって出ます）
2. カードを見て答えを思い浮かべ、「答えを見る」（PCはスペースキー）
3. 思い出せた度合いを「言えなかった／あいまい／言えた」から選ぶ（PCは 1／2／3 キー）
4. 全部終われば今日の分は完了です

- 新しい項目は1日4項目（設定で変えられます）。1項目から「名称→概要」と「概要→名称」の2枚のカードを作り、逆向きのカードは翌日以降に出します
- 次に出す日は、言えたら 1日→3日→7日→16日→35日 と伸び、言えなかったら翌日に戻ります
- 両方向とも16日間隔まで進んだ項目を「定着」と数えます
- そのほか：理解度テスト（予定には影響しない）、比較モード（似た項目の違い）、項目一覧と検索、進捗の詳細、記録の書き出し・読み込み

## 開き方

- **PC**：`index.html` をダブルクリック
- **スマホ**：GitHub Pages で公開したあと、Safari／Chrome で開いて「ホーム画面に追加」（公開はまだしていません）

学習記録は開いたブラウザの中（localStorage）だけに保存され、外部には送られません。PCとスマホの記録は別々なので、引き継ぐときは「設定・バックアップ」の書き出し／読み込みを使います。

## 項目を足す・直す

1. `build/items/` の分野別JSONを編集する（項目の形式は `docs/01_データ構造設計.md`）
2. 一次情報（厚生労働省の告示・通知・疑義解釈）で確かめた内容だけを書き、出典と確認日を `sources` に入れる
3. 確認が済んだ項目の `status` を `draft` から `active` にする
4. `build` フォルダで `python build.py` を実行する

`build.py` は、点数が空のままの項目・令和8年度以外のデータ・存在しない類似項目や出典などを見つけると、`index.html` を更新せずに止まります。一覧は `build/items.csv`（Excelで開けます）に書き出されます。

## ファイル構成

```
apps/shinryo-100/
├── index.html            ← 学習アプリ（build.py が生成。直接は編集しない）
├── manifest.webmanifest / sw.js / icons/   ← ホーム画面追加とオフライン対応
├── docs/                 ← 設計メモ（データ構造・100項目の選定・試作メモ）
└── build/
    ├── build.py          ← 検査とビルド
    ├── template.html     ← アプリ本体（HTML/CSS/JS）
    ├── meta.json         ← 適用年度・データ更新日・分野
    ├── sources.json      ← 出典台帳
    ├── items/*.json      ← 項目データ（分野ごと）
    └── items.csv         ← 生成物（一覧確認用）
```
